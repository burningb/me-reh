# 미래 me-Reh v0.3 — 로컬 Whisper로 실행하기 (맥)

인터넷이 없는 공연장에서도 노트북 안에서 음성을 인식합니다.
Whisper가 단어마다 시작·끝 시간을 알려 주므로, 크게·높게 말한 순간이 정확히 그 단어의 칸에 남습니다.

## 폴더 안의 파일

| 파일 | 하는 일 |
|---|---|
| `me-Reh_v0.3_live.html` | 자막 화면 |
| `mereh_whisper_server.py` | 노트북 안의 음성 인식 프로그램 (화면도 함께 띄움) |
| `setup_mac.command` | 처음 한 번 설치 (인터넷 필요, 약 2GB) |
| `start_me-Reh.command` | 실행 (인터넷 필요 없음) |

## 1. 처음 한 번: 설치 (인터넷 되는 곳에서)

1. 이 폴더를 원하는 곳(예: 문서 폴더)에 둡니다.
2. `setup_mac.command`를 **오른쪽 클릭 → 열기**를 누릅니다.
   - 처음에는 "확인되지 않은 개발자" 경고가 나올 수 있습니다. 오른쪽 클릭 → 열기로 열면 "열기" 버튼이 생깁니다.
   - 그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**를 누릅니다.
3. 터미널 창이 열리고 4단계가 진행됩니다. 마지막에 "설치가 끝났습니다"가 나오면 완료입니다. (10~20분 정도)

## 2. 공연 때: 실행 (인터넷 없어도 됨)

1. `start_me-Reh.command`를 엽니다. 처음에는 오른쪽 클릭 → 열기로 엽니다.
2. "준비 완료"가 나오면 Chrome에 화면이 자동으로 열립니다. 메뉴의 인식 방식은 **로컬 Whisper**로 되어 있습니다.
3. **● 마이크 시작**을 누르고 Chrome의 마이크 허용을 누릅니다.
4. 평소 목소리로 한두 문장 먼저 말해 음량 보정을 맞춘 뒤 시작하세요.
5. 끝나면 **누적 구성**(V 키)으로 바꾸고 **PNG 16:9 / PNG 세로**로 저장합니다. **기록 저장**(JSON)도 해 두면 나중에 포스터를 다시 뽑을 수 있습니다.

> 터미널 창은 공연 내내 열어 두세요. 닫으면 인식이 멈춥니다.

## 화면에서 보이는 것

- 말을 시작하면 글자가 오기 전에 **목소리 질감 칸**이 먼저 자라납니다.
- 말하는 동안 1초마다 **중간 글자**가 바뀌어 나타납니다.
- 말을 멈추고 0.7초쯤 지나면 그 문장이 Whisper로 다시 인식되어 **확정**됩니다. 이때 단어마다 실제 시간에 맞춘 크기·색이 붙습니다.
- 확정은 보통 말이 끝나고 0.5~1.5초 뒤에 됩니다.

## 문제가 생기면

- **"로컬 Whisper 인식 프로그램에 연결할 수 없습니다"**: `start_me-Reh.command` 창이 켜져 있고 "준비 완료"가 떴는지 확인하세요.
- **"모델을 불러오지 못했습니다"**: 설치 때 모델을 다 받지 못한 것입니다. 인터넷이 되는 곳에서 `setup_mac.command`를 다시 실행하세요.
- **확정이 너무 늦을 때**: 더 작은 모델을 씁니다. 터미널에서 이 폴더로 이동한 뒤
  `MEREH_MODEL=mlx-community/whisper-small-mlx bash setup_mac.command` 로 한 번 설치하고,
  `MEREH_MODEL=mlx-community/whisper-small-mlx bash start_me-Reh.command` 로 실행합니다. 대신 한국어 정확도는 조금 떨어집니다.
- **조용할 때 엉뚱한 문장이 나올 때**: Whisper는 무음에서 "시청해 주셔서 감사합니다" 같은 문장을 지어내는 버릇이 있습니다. 대표적인 문장은 걸러 내지만, 새로운 것이 보이면 `mereh_whisper_server.py` 위쪽의 `HALLUCINATIONS` 목록에 추가하세요.
- 인터넷이 되는 곳이라면 메뉴의 인식 방식을 **브라우저 인식**으로 바꿔도 됩니다.

## 참고

- 인식 프로그램은 이 노트북 안에서만 동작합니다(`127.0.0.1`). 소리는 밖으로 나가지 않습니다.
- 글꼴: 인터넷이 없으면 Noto Sans KR 대신 맥의 Apple SD Gothic Neo로 그려집니다.

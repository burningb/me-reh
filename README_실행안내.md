# 미래｜me-Reh — 로컬 MVP v0.2.3

## 바로 실행

1. `me-Reh_MVP_local_v0.2.3.html`을 Chrome 또는 Edge에서 열어 봅니다.
2. 마이크 권한이 거부되거나 기능이 제한되면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/me-Reh_MVP_local_v0.2.3.html`에 접속합니다.
3. 언어를 선택한 다음 **마이크 시작**을 누릅니다. 한국어·영어·일본어 인식을 선택할 수 있으나 브라우저 및 인식 서비스의 지원 여부에 따라 차이가 있습니다.
4. 화자 A/B를 수동으로 전환하고 각 화자의 크기·반응 강도·글꼴을 조정합니다.
5. **설정 로컬 저장**을 누르면 현재 브라우저에 설정을 보관합니다. JSON 내보내기·가져오기로 다른 PC에 설정을 전달할 수 있습니다.
6. 자막 기록은 **자막 기록 로컬 자동 저장(선택)**을 체크한 경우에만 브라우저에 저장합니다. **자막 기록 TXT 저장**은 현재 화면 세션의 기록을 파일로 내보냅니다.

## 무엇이 로컬인가?

- **로컬:** HTML·CSS·JavaScript 실행 파일, 설정 JSON, TXT 기록 내보내기, 선택적 `localStorage` 저장, 사용자가 선택한 로컬 글꼴.
- **로컬이 아닐 수 있음:** `SpeechRecognition`은 브라우저의 서버 기반 인식 서비스를 사용할 수 있습니다. 인터넷이 없으면 인식이 작동하지 않을 수 있습니다. Google Fonts의 신규 다운로드도 인터넷을 사용합니다.
- **완전 오프라인 전환은 미구현:** faster-whisper 등의 로컬 STT 서버·모델은 후속 개발 항목입니다.

## 보안과 개인정보

- 저장된 자막은 같은 브라우저 프로필에서 접근 가능할 수 있습니다. 공용 PC에는 사용하지 않는 편이 좋습니다.
- `로컬 데이터 삭제`는 이 앱 버전의 저장 키만 삭제합니다. 브라우저가 제공하는 음성 인식 서비스의 외부 처리 내역은 통제하지 못합니다.
- 녹음 파일 저장은 구현하지 않았으며, 자막 TXT 파일은 사용자가 직접 내보냅니다.
- JSON 가져오기에는 데이터 형식 검사를 적용하지만, 출처를 신뢰할 수 없는 파일은 사용하지 마세요.
- 로컬 폰트 파일은 브라우저 세션에만 적용되며, 가져온 JSON에는 포함되지 않습니다.

## 제한 사항

- 화자 구분은 수동입니다. 입력별 독립 인식과 음성-단어 타임코드 정렬은 없습니다.
- 음량/음높이는 실제 감정의 추정값이 아닙니다.
- `고대비·고정 자막`과 `모든 움직임 줄이기`를 별개로 제공합니다. 접근성 표준 준수 여부는 아직 평가되지 않았습니다.
- 이 버전은 JavaScript 구문 검사를 통과했으며, 실제 마이크·브라우저 검증 및 당사자 테스트는 필요합니다.
